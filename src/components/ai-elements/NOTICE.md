# AI Elements Vue attribution

These components adapt interaction and composition patterns from
[AI Elements Vue](https://github.com/vuepont/ai-elements-vue), a community Vue port inspired by
Vercel AI Elements.

AI Elements Vue is Copyright 2025 cwandev and licensed under the Apache License 2.0. The local
components were narrowed to OpenPencil's Vue, Reka UI, Tailwind, token, and density conventions;
they are not an official Vercel Vue package.
